# Duplicate Tab Inspector (v5.0.0)

Zero-background-load Chrome extension for reviewing and closing duplicate tabs.

## Features
- **Zero Background Load**: No passive listeners or background screenshot caching while browsing.
- **Sticky Header & 4-Step URL Filter**: Switch cleanly between `Exact`, `No Hash`, `Path`, and `Domain` matching levels.
- **On-Demand Bulk Previews**: Click `Capture Previews` in the header to capture snapshots of duplicate tabs only when requested.
- **Hover-Only Card Actions**: Hover any card to reveal window/recency metadata, full wrapped URL, `↗ Jump to Tab`, and the top-right `×` close button.
- **Static Custom Icon**: Crisp overlapping-tab PNG icons (`16px`, `48px`, `128px`) plus `icons/icon.svg`.

## Install
1. Open `chrome://extensions` in Chrome.
2. Enable **Developer mode**.
3. Click **Load unpacked** and select this extracted folder.
