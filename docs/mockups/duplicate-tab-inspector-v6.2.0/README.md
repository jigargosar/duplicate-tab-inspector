# Duplicate Tab Inspector v6.2.0

A minimal, zero-background-load Manifest V3 Chrome extension for inspecting and selectively closing duplicate tabs.

## Installation
1. Extract this archive to a local folder.
2. Open `chrome://extensions` in Chrome.
3. Enable **Developer mode** in the top-right corner.
4. Click **Load unpacked** and select the extracted folder.
5. Click the toolbar icon or press `Alt+Shift+D` to open the inspector.
