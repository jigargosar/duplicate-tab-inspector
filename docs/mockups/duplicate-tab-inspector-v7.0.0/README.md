# Duplicate Tab Inspector v7.0.0

Zero-background-load Manifest V3 Chrome extension to inspect, preview, and close duplicate tabs across windows.

## Install
1. Extract `duplicate-tab-inspector-v7.0.0.zip`.
2. Open `chrome://extensions` and enable **Developer mode**.
3. Click **Load unpacked** and select the extracted folder.
4. Click the toolbar icon or press `Alt+Shift+D`.
