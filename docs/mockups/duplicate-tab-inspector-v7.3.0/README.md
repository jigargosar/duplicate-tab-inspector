# Duplicate Tab Inspector (v7.3.0)

Lightweight Manifest V3 Chrome extension for inspecting, previewing, and selectively closing duplicate tabs across windows.

## Installation
1. Extract `duplicate-tab-inspector-v7.3.0.zip`.
2. Open `chrome://extensions` in Chrome.
3. Enable **Developer mode** (top-right).
4. Click **Load unpacked** and select the extracted folder.
