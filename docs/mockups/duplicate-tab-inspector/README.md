# Duplicate Tab Inspector

A minimal, zero-dependency Manifest V3 Chrome extension for previewing and selectively closing duplicate tabs.

## Load in Chrome
1. Extract this zip archive into a permanent folder.
2. Open `chrome://extensions` in Chrome.
3. Enable **Developer mode** (top-right toggle).
4. Click **Load unpacked** and select the extracted folder.
5. Pin **Duplicate Tab Inspector** to your toolbar (or press `Alt+Shift+D`).

## Features
- **Manual control only:** Never closes tabs automatically in the background.
- **Multi-level URL grouping:** Toggle **Domain**, **Path**, **Query** (sorted parameters), and **Hash** levels live.
- **Interactive preview:** Click any tab row to jump to and inspect that tab before closing, close individual tabs, or close extra copies per group while keeping the active/first tab.
